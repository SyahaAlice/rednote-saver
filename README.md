# 多功能媒体下载器（MediaDownloader）

一个完全由你自己掌控的 iOS App，替代已失效的「小红书助手pro」和 HyperTaps：

- **下载**：小红书笔记的原图、原视频，实况图自动存成**真正可以长按播放的实况照片**；抖音、快手、Instagram 有各自的解析；其它网站的视频用内置的 **yt-dlp**，图片和图文混排用内置的 **gallery-dl**（X、微博、Pixiv、Bluesky、Reddit 等几百个网站）。
- **不过滤内容**：App 不按内容类型、敏感标记、年龄分级筛选或拦截，也没有网站黑名单；网站给什么就存什么。一个链接里有多少项都会列出来，没有数量上限。
- **实况工具**：视频转实况（截取最长 5 秒、可选封面帧）、实况拆分（拆成照片 + 视频）。
- **号池**：电脑上整理好的 cookies 文件放进 App 的 `cookies` 文件夹即可使用，换 cookie 不用重新安装。
- **原图优先**：原图 / 原片拿不到时会先问你，同意后才改存网页压缩版。

实况照片在手机本地合成：图片写入 Apple MakerNote 配对 ID，视频写入 QuickTime content identifier 和 still-image-time 元数据轨道，再用 PhotoKit 作为同一个项目导入相册。不依赖任何第三方合成模块或服务器。

## 一、编译（GitHub Actions）

iOS App 只能在 macOS 上编译，所以借用 GitHub 提供的 macOS 机器。

1. 在 GitHub 上新建一个仓库，把本目录（`ios-app`）里的全部内容作为仓库根目录推上去。
   - **公开仓库**：macOS 编译完全免费，不限分钟数。代码别人能看到，但里面没有任何账号、密码或密钥。
   - **私有仓库**：免费账号每月 2000 分钟额度，macOS 按 **10 倍**消耗，相当于每月约 200 分钟；一次编译大约 3–5 分钟，够用。
2. 每次推送代码都会自动编译。也可以在仓库的 **Actions → Build unsigned IPA → Run workflow** 手动运行。
3. 编译完成后，main 分支的 ipa 会自动发布到仓库的 **Releases → latest**，直接下载 `XHSSaver.ipa` 即可，不用登录：
   `https://github.com/SyahaAlice/rednote-saver/releases/download/latest/XHSSaver.ipa`
   - 每次运行记录页面底部的 **Artifacts** 里也有一份（需要登录 GitHub 才能下载）。

## 二、第一次安装（只需做一次，约 30–40 分钟）

> 所有需要输入 Apple ID 密码的步骤都由你本人操作。建议**专门注册一个 Apple ID 小号**，因为它的密码会保存在 AltServer 里。

### 电脑（Windows）

1. 从 **Apple 官网**下载安装 **iTunes** 和 **iCloud**。
   - 不能用微软商店版，否则 AltServer 识别不到手机。如果已经装了商店版，先卸载再装官网版。
2. 从 altstore.io 下载安装 **AltServer**。
   - 运行后它会常驻在任务栏右下角。
   - 把它加入开机自启：按 `Win + R` 输入 `shell:startup`，把 AltServer 的快捷方式放进去。
3. 用数据线连接 iPhone，在手机上点「信任此电脑」。
4. 打开 iTunes，点手机图标，在「摘要」里勾选 **「通过 Wi‑Fi 与此 iPhone 同步」**，然后点「应用」。
   - 这一步决定了以后能不能**无线自动续签**。
5. 点任务栏的 AltServer 图标 → **Install AltStore** → 选择你的 iPhone，然后输入 Apple ID 小号和密码（你本人输入）。

### 手机

6. **设置 → 隐私与安全性 → 开发者模式**：打开，手机会重启，重启后确认开启。
7. **设置 → 通用 → VPN 与设备管理**：点你的 Apple ID，选「信任」。
8. 现在主屏幕上应该有 AltStore 了。

### 安装多功能媒体下载器

9. 两种方式，任选一种：
   - **电脑上装**：点任务栏 AltServer 图标，按住 `Shift` 点 **Sideload .ipa…**（新版本直接点 **Sideload .ipa…**），选择你的 iPhone 和 `XHSSaver.ipa`。
   - **手机上装**：把 `XHSSaver.ipa` 存到手机「文件」App 里，打开 AltStore → **My Apps** → 左上角 **+** → 选择这个 ipa。
   - **以后更新不用传文件**：在 AltStore 的 **Sources** 里点 **+**，填入下面的地址添加一次。之后每次有新版，**My Apps** 顶部会出现它，点 **Update** 就装好了（电脑上的 AltServer 要开着，和手机在同一个 Wi-Fi）。
     `https://github.com/SyahaAlice/rednote-saver/releases/download/latest/apps.json`

> 安装和续签尽量只用一边：要么都在手机的 AltStore 里做，要么都在电脑的 AltServer 里做。两边各自登录 Apple ID 可能各申请一张签名证书，免费账号只能有一张有效，新的会让旧的作废，用旧证书装的 App 会提示「不再可用」，需要重新安装（不要先删除 App，覆盖安装能保留数据）。
10. 第一次打开 App、点保存时，会询问「添加照片」权限，选**允许**。

> **安装报错怎么办**
> - `The app could not be found`：ipa 所在路径里有中文。把 ipa 放到纯英文路径（例如 `D:\Apple\XHSSaver.ipa`）再选。
> - `The name for this app is invalid`：旧版本的问题（App 名称是中文），用最新的 ipa 即可。
> - `WinHttpReceiveResponse: 12030`：连接 Apple 服务器时网络中断，重试一次。

> 免费账号最多同时装 3 个侧载 App，AltStore 自己占 1 个。

## 三、每周自动续签

免费证书 **7 天过期**。过期后 App 打不开，但数据和相册里的照片都不受影响，续签后就能恢复。

**AltStore 会自动续签**，只要同时满足：

- 电脑开着，AltServer 在运行（已设开机自启）；
- 手机和电脑连在**同一个 Wi‑Fi**；
- 已经勾选「通过 Wi‑Fi 与此 iPhone 同步」。

系统的后台刷新时间不太可控，建议再加一个**快捷指令自动化**，让续签更可靠：

1. 打开「快捷指令」→ 底部 **自动化** → 右上角 **+**。
2. 触发条件选 **充电器 → 已连接**，或者 **特定时间 → 每天凌晨 3:00**。
3. 选择 **立即运行**，关闭「运行前通知」。
4. 添加操作：搜索 AltStore，选 **Refresh All Apps**。

**手动续签**：打开 AltStore → My Apps → 左上角 **Refresh All**，大约 1 分钟。每个 App 下方会显示还剩几天到期。

**出门在外**：如果 7 天内都连不上家里的电脑，App 会过期。回家连上同一个 Wi‑Fi 后点 Refresh All 就能恢复。

**备用方案**：AltStore 出问题时，可以用 Windows 上的 **Sideloadly** 手动重签同一个 ipa，每周大约 2 分钟。

## 四、使用

### 下载

- **App 里**：复制分享文案或链接 → 打开「多功能媒体下载器」，点输入框下面的「粘贴」（有内容之后同一个位置变成「清空」）。打开旁边的「自动粘贴」开关后，每次打开 App 或切回来，剪贴板里的新文字会**自动填进输入框**；这时系统可能先弹「允许粘贴」，不想每次都被问，到系统「设置 → App → 多功能媒体下载器 → 从其他 App 粘贴」选「允许」。然后二选一：
  - **解析**：先预览。预览页列出这个作品里的每一张图片、实况和视频，默认全选，点一下取消某一项；有多种清晰度的视频可以在这里选（默认最高，一次对其中所有视频生效）。点 **保存到相册** 后进入整理页选相册，然后开始下载。
  - **快速保存**：不预览、不问放哪个相册，链接里的内容全部保存，视频取最高清晰度。有完全匹配的相册会自动放进去（见下面「相册归类」）。超过 20 项（主页、合集）时会先问一句。
- **分享菜单一键保存**：
  1. 打开「快捷指令」，新建一个快捷指令。
  2. 点底部 **ⓘ（简介）**，打开 **在共享表单中显示**，接收类型勾选 **URL** 和 **文本**。
  3. 添加操作 **下载到相册**（来自「多功能媒体下载器」），参数设成「快捷指令输入」。想跳过预览就打开操作里的「快速保存」。
  4. 在小红书、B 站等 App 里点分享，选这个快捷指令。
- **快捷指令里的三个操作**：
  - **下载到相册**：打开 App 在前台做。输入链接或分享文案，输出一句结果（比如「已保存 6 张图片」）。「快速保存」开关决定要不要预览。
  - **后台快速保存**：不打开 App，在后台全部保存，视频取最高清晰度。系统只给后台操作约 30 秒，适合图文和短视频，大视频、合集请用上一个。后台没有界面，所以：要用内置浏览器读取的网站（抖音、Instagram、X、微博、快手等）直接报错；本来要问你的地方一律按「不同意」处理（保存过的不再存、原图拿不到的那一项跳过、超过 20 项的合集不存），并在结果里说明。第一次用之前先在 App 里保存过一次，把相册权限给好。
  - **获取下载直链**：打开 App 在前台做。只解析，不保存，输出地址列表（视频取最高清晰度），可以接「拷贝到剪贴板」「重复」等操作。有些网站的地址有时效，或者要带登录信息才能下。
- **解析到东西才往下走**：链接里没有解析到图片和视频时直接报错，不会弹出预览和选相册。不限制网站：没有专门解析器的网址（包括短链）都会交给 gallery-dl 和 yt-dlp 去试，能不能成由它们决定。
- **下载直链**：解析完后，预览页和「下载」页都有一栏「下载直链」，点开能看到每一项的地址，点一下复制，也可以「复制全部」。
- 进度显示在「下载」页：按顺序列出走过的每一步（解析、等你确认、下载、下载并存入相册），进行中的那一步显示进度（比如「3 / 9 · 37%（12 / 30 MB）」）；下面是最近一条关键信息。长网址不在这里显示，细节点开「过程」。保存过程中可以点「取消」中止。
- **内置浏览器读取不弹页面**：抖音、Instagram、X、微博、快手是用内置浏览器读取的，现在在后台进行，下载页只显示步骤和结果。等了约 25 秒还没读到（多半是网站要登录或验证）时，会问你要不要打开页面自己处理。
- **后台继续**：保存期间屏幕不会自动锁定。iOS 26 及以上，开始下载后切到别的 App 或锁屏也会接着下，进度显示在灵动岛 / 锁屏上；系统资源紧张时仍可能中止。更早的系统切走后只能多跑约 30 秒。
- 登录和 cookie 相关的界面都在「设置 → 账号」。保存失败需要登录时，App 会问你要不要过去，并直接打开那个网站的登录页；登录后回到「下载」再保存一次。
- **自动续期登录**（设置 → 账号，默认开）：打开 App 时，每个登录过的账号每天最多一次在内置浏览器里打开网站首页，让网站自己延长登录，再把最新的 cookie 同步到号池。续完发现账号已经掉线（被踢下线、到期）时，下载页顶上会提示，可以直接去重新登录。到期就必须重登的网站续不上；除小红书外，「被踢下线但 cookie 还在」的情况要到下载失败时才看得出来。账号那一行的「同步到号池」只是把内置浏览器里现有的 cookie 抄过去，不访问网站。
- **导出 / 导入账号**：「设置 → 账号 → 导出全部账号」把所有账号的 cookie 存成一个 JSON 文件；重装或换手机后用「从文件导入」放回来，内置浏览器里的登录状态也一起恢复。同名的账号会被换成文件里的；也可以直接导入一个 Netscape 格式的 cookies 文件。导出的文件等于登录凭证，不要发给别人，也不要放进仓库。
- 保存过的作品会记进下载记录；有失败项时不记，方便之后重新保存。

| 来源 | 保存结果 |
|---|---|
| 小红书图文 | 每张图的原图（通常是 HEIC） |
| 小红书实况图 | 实况照片；普通图存原图 |
| 小红书视频 | 原视频 |
| Instagram | 图片、多图、视频，每一项都取最高分辨率（需要登录，见下） |
| 快手 | 图集的每张图、单图、视频；游客就能存，拿不到数据时再用登录账号（见下） |
| B 站 | 视频（最高清晰度）+ 封面图（原始尺寸）；可在设置里改成只存封面或不存封面 |
| X、微博 | 一个帖子里的图片和视频全部保存：X 存原图，微博存最大尺寸，微博实况图存成实况照片（见下） |
| Pixiv、Bluesky、Reddit、Tumblr 等 | gallery-dl 支持的网站：帖子里的图片（和它能直接给出的视频）全部保存 |
| 其它网站 | yt-dlp 下载，默认取能拿到的最高清晰度，预览页里可以改；同清晰度优先 H.264，只有更高清时才用 HEVC；音视频分开的自动合并。相册不支持的格式存到「文件 → 多功能媒体下载器 → 下载 → 相册名或平台名」。一个链接里有多个视频（多视频帖子、合集）时全部保存，超过 20 项会先问你，单次最多 100 项 |

**原图 / 原片拿不到时**会弹窗询问：改存这一项、本次全部改存替代版本，或跳过。实况合成失败时也会先问你是否只存静态图。

### 实况工具

- **视频转实况**：从相册或「文件」选一段视频，拖动滑块选开始位置、时长（最长 5 秒）和封面帧，生成实况照片存进相册。
- **实况拆分**：选一张实况照片，拆成一张照片 + 一段视频存进相册，并在「文件 → 多功能媒体下载器 → 实况拆分」里各留一份。

### 保存设置（设置 → 保存）

- **小红书图片格式**：默认 **HEIC 原图**（小红书原文件，体积最小）；也可选 JPEG 或 PNG（无损），由小红书服务器从原图转换，分辨率不变。原图拿不到时会先问你，替代顺序是「全尺寸 JPEG → 网页压缩图」。
- **B 站封面**：和视频一起保存（默认）、只保存封面、不保存。
- **照片日期用作品发布时间**（默认关）：打开后相册里按原帖时间排序。
- **下载记录**：只记「平台:作品ID → 时间」，一万条也不到 1 MB，放在 App 内部数据里（「文件」App 看不到）；保存过的作品再存时会先问你；清空前会再确认一次。

### 相册归类

相册这部分是三件分开的事：

- **命名**：相册名按模板从账号信息生成（规则在「设置 → 相册命名」）。
- **匹配**：已有相册和这次的作者对不对得上，分三档：

  | 档 | 判断 | 例子（作者的小红书号是 `1666871946`） |
  |---|---|---|
  | 完全匹配 | 相册名里有按规则写的「前缀 + ID」 | `安安（xhs_1666871946）` |
  | 含有这个 ID | 相册名里出现了这个 ID，但不是按规则写的 | `安安 1666871946` |
  | 仅用户名相同 | 只对上了昵称，可能是同名的其他作者 | `安安的图` |

- **存入**：两个入口不一样。
  - **快速保存**：恰好有一个「完全匹配」的相册就直接放进去，不问；没有、或者不止一个，就不放相册，照常保存。不会新建相册，也不会给相册改名。
  - **解析**：预览之后进入「放进哪个相册」页：
    - 最上面一行是**这次的作者**（平台、用户名、ID）。ID 没取到、或者想加这个作者的其它账号（小号、别的平台），点「改作者」。小红书用的是**小红书号**（不是用户 ID）；抖音是抖音号；X / Instagram 是 @ 后面的用户名；B 站是 UID。
    - 中间是**已有相册**（带封面和数量，按上面三档标出，有完全匹配的默认选中）、**新建相册**（名字自动生成，可以直接改，可选「已注销 / 常删作品」格式）和**不放入相册**。
    - 底部是**搜索框**和按钮。知道是同一个作者、但名字对不上的相册，在搜索框里输入文字，列表就换成搜索结果。主按钮写着现在选的是什么，点它**直接放入，不会问改名**。
    - 想把这次的账号写进相册名（以后这个账号就能自动对上），选中相册后点主按钮旁边的「改名…」：App 按规则拟一个新名字（原名保留，接上这次的账号），**你可以随便改**，然后「改名并放入」。

  保存结果里会写明存到了哪：「放进了相册「xxx」」或「没有放入相册（在图库里）」；放进了相册的话，下面有「查看相册」。

  相册名的格式：

  | 格式 | 例子 |
  |---|---|
  | 常规 | `用户A（xhs_idA）`、`用户B（x_@idB）`、`用户C（ins_@idC）`、`用户D（UID:idD）` |
  | 多平台 / 多账号 | `用户E1（dy_idE1）/用户E2（wb_idE2）` |
  | 已注销 / 常删作品 | `用户F【ks_idF】` |

**「相册」页**（第二个标签）用来整理你自己建的相册，不用再去系统的「照片」App 里翻：

- 列出全部相册，带封面和数量，标出名字是按规则写的还是手写的。
- 底部是搜索框和筛选：「手写的名字」只看不符合命名规则的；「可能重复」把名字里有同一个 ID 或同一个用户名的相册排在一起。
- 「多选」之后可以把几个相册合并成一个。
- 点进一个相册能看里面的照片和视频，底部可以改名、合并到别的相册、选择照片后移出或移到别的相册、删除相册。
- 这些操作都**不会删照片**：合并、移出、删除相册之后，照片还在图库里。

**命名规则可在 App 里改**（设置 → 相册命名，两组设置默认收起，点开再改）：

- **ID 前缀**：小红书 `xhs_`、抖音 `dy_`、快手 `ks_`、微博 `wb_`、B 站 `UID:`、X `x_@`、Instagram `ins_@`；没列出的中文平台自动取小写拼音首字母（西瓜视频 → `xgsp_`），也可以手动添加平台。
- **模板**：占位符 `{用户名}` `{前缀}` `{ID}`；常规默认 `{用户名}（{前缀}{ID}）`，已注销默认 `{用户名}【{前缀}{ID}】`，多账号分隔默认 `/`，带实时预览。

相册归类需要「**完整照片访问**」权限（要读取已有相册名）；不给也能正常保存，只是跳过归类。有完整权限时，存完实况照片还会回读确认它确实被识别成实况。

### 账号（在 App 内登录）

「设置 → 账号」是一个列表，下载时会用到的所有账号都在这里：在 App 里登录的账号，和从电脑导入的 cookies 文件（见下面的「号池」）。每行显示来源、网站和登录状态。

「添加账号」，选网站（抖音、小红书、哔哩哔哩、微博、Instagram，或任意登录网址），在弹出的 App 内置浏览器里登录，点「完成」。

- 每个账号有**独立的登录状态**（互不干扰），登录后 cookie 会自动以 Netscape 格式写进号池，yt-dlp 和小红书解析直接使用。
- 登录页底部出现绿色的「已经登录成功」就可以点「完成」，不用等网页自己跳转（X 登录后网页有时会一直转圈）；页面卡住可以点右下角的「重新加载」。
- cookie 失效时点「**重新登录**」；「刷新 cookie」会把当前登录状态重新导出一次。
- 快手的登录页用的是它的账号登录页（桌面版网页）：快手主页在手机浏览器里只会让你「打开 App」，登录不了。
- 抖音、小红书在手机上登录可以用手机号 + 验证码（同一台手机没法扫自己屏幕上的二维码）。

### 抖音

抖音现在不登录拿不到作品数据（分享页里不再带数据，作品详情接口对未登录访问返回 403），所以**必须先添加一个抖音账号并登录**。

保存时 App 会弹出内置浏览器，用你的抖音账号打开作品页（桌面版网页，等同 Safari 的「请求桌面网站」），由抖音自己的网页请求作品详情，App 只是复制一份网页收到的数据：

| 作品 | 保存结果 |
|---|---|
| 视频 | 最高清晰度（实测最高 2160×3840 HEVC）；最高档下载失败时先问你，再改用次一档 |
| 图文 | 每张图的最高分辨率（抖音只提供压缩版 JPEG，没有原图） |
| 带动图的图文 | 实况照片 |

如果抖音要求验证，直接在弹出的页面里完成，再点「重新加载」。App 不伪造签名、不伪装浏览器。

### Instagram

yt-dlp 只能取 Instagram 的视频，图片帖子存不了，所以帖子链接（`/p/`、`/reel/`、`/tv/`、分享短链）由 App 自己解析，做法和抖音一样：**先在「设置 → 账号」里添加一个 Instagram 账号并登录**，保存时 App 弹出内置浏览器，用你的账号打开帖子，复制一份网页自己拿到的帖子数据。

| 帖子 | 保存结果 |
|---|---|
| 单张图片 | 最高分辨率的那一张 |
| 多图 / 图片和视频混排 | 每一项都保存，图片存图片、视频存视频 |
| 视频 / Reels | 最高清晰度；失败时先问你，再改用次一档 |

还没在 App 里登录 Instagram 时，照旧用 yt-dlp 试（只能存视频）；失败会提示「登录后重试」。如果 Instagram 要求登录或验证，直接在弹出的页面里完成，再点「重新加载」。其它 Instagram 链接（主页、快拍等）仍然走 yt-dlp。

### X 和微博

按顺序试三种办法，前一种拿到内容就不再往下：

1. **gallery-dl**：把帖子里的图片和视频一起列出来，图文混排也不会漏。X 基本都需要账号（号池里有 X 的 cookie 才行），微博游客通常就可以。
2. **yt-dlp**：只能拿视频。
3. **内置浏览器**：用你在「设置 → 账号」里登录的 X / 微博账号打开这条帖子读取数据，做法和 Instagram 一样；还没登录时会提示「登录后重试」。

| 帖子 | 保存结果 |
|---|---|
| X 图片 | 每张图的原图（`name=orig`） |
| X 视频 / 动图 | 码率最高的 mp4 |
| 微博图片 | 每张图的最大尺寸；实况图存成实况照片 |
| 微博视频 | 最高清晰度 |

转发的帖子存的是被转发的原帖内容。

### 其它网站的图片（gallery-dl）

[gallery-dl](https://github.com/mikf/gallery-dl) 是和 yt-dlp 同类的开源项目，专门做图片和图文混排。没有专门解析器的网站，App 先问它：它支持就把帖子里的内容全部列出来由 App 保存；它不支持（比如 YouTube、B 站视频）就交给 yt-dlp。

- 小红书、抖音、快手、Instagram 帖子不走它，用各自的解析。
- 有的网站要账号：把那个网站的 cookies 放进号池即可。Pixiv、Reddit、Tumblr 在 gallery-dl 里需要额外授权，不保证能直接用。
- 网站改版导致保存失败时，「设置 → 下载器 → 更新 gallery-dl 到最新版」，从 Python 官方软件源下载并校验，不用重新安装 App。

### 快手

快手的分享链接由 App 自己解析，取数据的位置参考了开源项目 [KS-Downloader](https://github.com/JoeanAmier/KS-Downloader)：作品数据写在分享网页里，图集每张图的地址由图片服务器名和图片路径拼成。

| 作品 | 保存结果 |
|---|---|
| 图集 | 每一张图片 |
| 单图 | 那一张图片 |
| 视频 | 网页给出的最高清晰度 |

App 先以游客身份直接请求网页；拿不到数据时（比如快手要求验证），如果在「设置 → 账号」里登录过快手，就改用内置浏览器打开，由你在页面里完成验证；都不行再试 yt-dlp。和 KS-Downloader 不同，App 不伪装浏览器。

### B 站封面

保存 B 站视频时，封面图（原始尺寸）会作为一张图片存进同一个相册。「设置 → 保存 → B 站封面」可以改成「只保存封面」（不下载视频，用来单独提取封面）或「不保存」。封面地址来自内置的 yt-dlp（开源）解析出的作品信息。

### 号池（cookies）

App 的文件夹会出现在「文件 → 我的 iPhone → 多功能媒体下载器」里，号池就在其中的 `cookies` 文件夹：

1. 电脑上照旧用 Get cookies.txt LOCALLY 导出，再用 `merge_cookies.py` 把同一账号的多个域名合并成一个 `.txt`。
2. 把文件推到手机（Bundle ID 在 App 的「设置」页里能看到，AltStore 会在原 ID 后面加上你的团队 ID）：
   ```bash
   opendevice afc push --app <Bundle ID> --documents cookies/merged/au.txt /cookies/
   ```
   或者用 AirDrop / 「文件」App 直接拷进 `cookies` 文件夹。
3. 「设置 → 账号」里点「重新读取」，导入的文件会和 App 内登录的账号列在一起，标着「电脑导入的文件」，显示包含哪些网站、登录状态（只显示名字，不显示内容）。失效的文件可以点「用内置浏览器补登」：会多出一个 App 内登录的账号，原来的文件不会自动删除，确认不用了再左滑删掉。

规则与 `phone/dl.py` 相同：按网址自动挑出对应网站的账号轮流使用；小红书**先用游客**（游客能拿到原片），失败才用账号；其它网站账号优先、游客垫底。

> cookie 只存在手机上，不会进入仓库或安装包。仓库和 ipa 都是公开的，**不要把 cookies 文件提交到 GitHub**。

### 更新 yt-dlp

网站改版导致下载失败时，打开「设置 → 更新 yt-dlp 到最新版」，App 会从 yt-dlp 官方 GitHub 下载最新版并立即生效，不用重新安装。出问题时可以「恢复内置版本」。gallery-dl 同理，旁边有它自己的更新和恢复按钮。

## 五、离线检查解析逻辑

yt-dlp 和 gallery-dl 这一路（选格式、多项下载、取消、列出图片、不过滤内容）可以在电脑上直接测，不访问外网：

```bash
python tools/test_dlcore.py
```

小红书的解析逻辑：

```bash
python tools/parse_proto.py --html 已保存的笔记网页.html 笔记ID
```
